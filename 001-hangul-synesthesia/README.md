# #001: 한글 공감각 (Hangul Synesthesia)

한글을 타이핑하면 각 자모가 고유한 **색상 파티클**과 **음**을 동시에 생성하는 인터랙티브 공감각 아트 앱입니다.

## 원리

한글 글자를 초성/중성/종성으로 분해하여:

- **초성** → 색상(hue) + 음 높이(frequency) + 파티클 행동
  - 파열음(ㄱ,ㄷ,ㅂ...): 폭발형 파티클
  - 비음(ㄴ,ㅁ,ㅇ): 부유형 파티클
  - 마찰음(ㅅ,ㅆ,ㅎ): 분사형 파티클
  - 유음(ㄹ): 나선형 파티클
  - 파찰음(ㅈ,ㅉ,ㅊ): 지그재그 파티클
- **중성** → 음색 + 밝기 (양성모음=밝고 따뜻, 음성모음=어둡고 차가움)
- **종성** → 파티클 수 증가 + 서브베이스 음 추가

## 사용법

1. `index.html`을 브라우저에서 열기
2. 한글 입력 → 소리와 빛이 동시에 생성
3. Enter로 문장 확정, 계속 입력
4. 지우기/저장/전체화면 버튼 활용

## 기술 스택

- 순수 HTML + CSS + JavaScript (단일 파일)
- Canvas API (파티클 렌더링)
- Web Audio API (실시간 음 합성, 펜타토닉 스케일)
