# Daily Coding Challenge

매일 하나의 작은 프로젝트를 만들며 코딩 감각을 유지하는 챌린지입니다.

## 규칙

- 하루에 하나의 완성된 프로젝트를 만든다
- 순수 HTML/CSS/JS 또는 적절한 기술 스택을 자유롭게 사용한다
- 흔한 앱이 아닌, 독창적인 아이디어를 추구한다
- 각 프로젝트는 `dayXXX-프로젝트명/` 폴더에 저장한다
