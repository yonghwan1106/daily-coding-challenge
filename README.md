# Daily Coding Challenge

**Claude Code의 능력을 십분 발휘하여, 세상에 없는 앱을 매일 하나씩 만드는 오픈소스 챌린지입니다.**

단순한 토이 프로젝트가 아닌, 창업으로 연결 가능한 독창적인 제품을 프로토타이핑합니다.

## 원칙

- 기존에 없는 독창적인 컨셉만 만든다
- Claude Code(AI)를 최대한 활용하여 하루 만에 동작하는 프로토타입을 완성한다
- 각 프로젝트는 사업화 가능성을 염두에 둔다
- 기술 스택은 목적에 맞게 자유롭게 선택한다
- 모든 코드는 오픈소스로 공개한다
- 각 프로젝트는 `dayXXX-프로젝트명/` 폴더에 저장한다

## 진행 현황

| Day | 프로젝트 | 설명 |
|-----|---------|------|
| 001 | [한글 공감각](day001-hangul-synesthesia/) | 한글 자모를 색상 파티클 + 음으로 변환하는 인터랙티브 공감각 아트 |
| 002 | [소리 캔버스](day002-voice-canvas/) | 마이크 소리의 음량·주파수·음색을 실시간 브러시 스트로크로 변환하는 인터랙티브 아트 |
