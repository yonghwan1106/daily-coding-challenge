# #002: Voice Canvas (소리 캔버스)

**소리로 그리는 캔버스 — 당신의 목소리가 작품이 됩니다**

마이크로 소리를 입력하면 소리의 물리적 특성(음량, 주파수, 음색)이 실시간으로 시각적 브러시 스트로크로 변환되어 그림이 그려지는 인터랙티브 아트 앱입니다.

## 소리 → 시각 매핑

| 소리 속성 | 시각 속성 | 매핑 |
|-----------|-----------|------|
| 음량 (amplitude) | 브러시 크기 | 작은 소리 = 가는 선, 큰 소리 = 굵은 획 |
| 주파수 (pitch) | 색상 (hue) | 저음 = 빨강/주황, 중음 = 초록/파랑, 고음 = 보라/분홍 |
| 스펙트럼 분포 | 투명도 | 단일 주파수 = 선명, 넓은 스펙트럼 = 반투명 |
| 소리 유무 | 브러시 on/off | 무음이면 그리지 않음 |

## 브러시 경로 모드

- **Orbit**: 원형 궤도를 따라 그림 → 만다라 패턴 생성
- **Free**: 마우스/터치 위치를 따라 그림 → 자유로운 드로잉
- **Wave**: 좌→우 파동 형태 → 사운드웨이브 시각화

## 기능

- 실시간 음량 미터 & 주파수/음정 표시
- 잔상(trail) 효과 토글
- 캔버스 지우기 / PNG 저장 / 전체화면
- 키보드 단축키 (1/2/3: 모드, C: 지우기, S: 저장, F: 전체화면, T: 잔상)
- 모바일 터치 지원

## 사업화 가능성

- **음악 교육**: 소리의 특성을 시각적으로 이해
- **미술 치료**: 소리/음악으로 감정을 표현하는 새로운 매체
- **접근성 도구**: 손을 쓰지 못하는 사용자를 위한 아트 도구
- **인터랙티브 전시**: 관람객 참여형 미디어 아트

## 기술 스택

- 순수 HTML + CSS + JavaScript (단일 파일, 프레임워크 없음)
- Web Audio API (`getUserMedia` + `AnalyserNode` FFT)
- Canvas API (radialGradient 브러시)

## 실행 방법

```bash
# 로컬 서버로 실행 (HTTPS 필요 시)
npx serve .

# 또는 단순히 index.html을 브라우저에서 열기
```

> 마이크 권한을 허용해야 동작합니다.
