# Day 001: 한글 타자 속도 테스트

한글 문장을 입력하며 타자 속도(타/분)와 정확도를 측정하는 웹 애플리케이션입니다.

## 기능

- 25개의 한글 문장 (속담, 명언, 일반 문장)
- 실시간 글자별 피드백 (정답: 초록, 오답: 빨강)
- WPM(타/분) 실시간 계산
- 정확도 측정
- 자동 타이머 (첫 입력 시 시작)
- 결과 화면 및 등급 시스템
- 키보드 단축키: `Esc` 다시 시작, `Tab` 다음 문장

## 등급 시스템

| 타수 (타/분) | 등급 |
|-------------|------|
| 0-99 | 거북이 |
| 100-199 | 토끼 |
| 200-299 | 말 |
| 300-399 | 치타 |
| 400+ | 번개 |

## 사용법

`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

## 기술 스택

- 순수 HTML + CSS + JavaScript (단일 파일)
- 외부 라이브러리 없음
